# Employee profile images

Create one folder per employee and place an approved profile image inside it. Example:

```text
data/people/
  README.md
  EMP001/
    profile.jpg
  EMP002/
    profile.png
```

Do not commit actual employee photos or personal data to Git. Add local content only on the machine that owns the archive, and restrict filesystem permissions. Keep a separate record of the authorized purpose, employee notice/consent where applicable, retention policy, and who may access these files.

This folder is for profile images and administrative organization only. Face embeddings or identity matching are not generated by the initial backend scaffold. Add biometric matching only after explicit institutional authorization, legal/privacy review, and validation of the model license and performance.
